# Socks5Proxy 原生 macOS 客户端

SwiftUI 本机管理版 0.2.1。系统侧栏、系统字体、SF Symbols、深浅外观和菜单栏入口。界面管理已部署的应用代理，不新增 TUN、DNS 设置或服务器部署。

## 功能

- **连接**：显示后台服务、PAC、豆包直连规则与域名组可用状态；启动/停止现有管理器。
- **域名分流**：普通、海外AI两组。海外AI包括OpenAI/Codex与Claude，共用节点偏好和探测决策，任一服务失败影响整组。实际出口两处HTTPS地区结果一致且非HK/MO才可用于该组；未知、过期或被排除地区的节点不能选用。地区结果不证明平台资格。
- **域名查询**：读取当前回环 PAC；只接受域名，拒绝 URL、授权参数和命令参数。
- **设置**：控制既有 LaunchAgent 的登录自启动，选择可信的项目目录。
- **菜单栏**：查看状态、打开窗口、刷新。退出界面不会停止后台代理。

“代理已就绪”要求运行状态新鲜、管理器 PID 与 launchd 一致、HTTP8888/PAC8090可用、Wi-Fi采用本项目PAC。若某域名组没有可用节点，显示“部分通道可用”。可达状态不是登录或模型生成成功的证明；毫秒为既有HTTPS探针首响应，不是带宽。

## 运行

本机构建：Apple Silicon，macOS 13及以上。需要已部署的 `dist/overseas-proxy` 及当前用户 LaunchAgent、现有Python运行时（优先复用已有桌面运行时，否则使用系统 `/usr/bin/python3`）；域名查询需要现有 Node.js。代理管理器仍依赖自己的既有Python和Go客户端。首次打开只读状态，不自动启动/停用代理，不安装启动项，也不复制密钥。

解压 `Socks5Proxy-Mac-0.2.1.zip` 后打开 `Socks5Proxy.app`。默认读取 `~/Documents/socks5proxy`；设置页可以选择自己的可信项目。界面只管理与该目录匹配的既有启动项，拒绝管理指向其他目录的启动项。

本版为本机管理客户端，**不是另一台电脑开箱即用的独立代理安装器**。App不包含Go代理核心、Python/Node运行时、生产配置或凭据。另一台Mac必须先独立准备运行环境。独立安装版需另行实现配置导入、运行时打包、网络服务适配与安装流程。

## 单实例与窗口行为

0.2.1起，同一macOS用户只允许一个新版客户端进程和一个主窗口。重复双击、从多个新版副本启动或直接运行可执行文件，只向已有实例发送固定唤起信号，新进程退出；不修改代理配置。

关闭窗口只隐藏主窗口，重复打开、Dock入口或菜单栏可恢复同一窗口。菜单“退出客户端”真正退出界面，锁随进程退出自动释放；退出/崩溃后可再次启动，无需删锁文件。单实例锁保存在 `~/Library/Application Support/Socks5Proxy/client.lock`，仅包含进程号，目录0700、文件0600，拒绝符号链接与硬链接。它不与代理管理器共享锁、不停止后台代理。

首次升级请正常退出0.2.0及更早旧版界面再打开新版；旧二进制本身没有单实例机制，不能保证继续启动旧版时也受新版限制。新版检测到旧版运行会优先唤起旧版并退出，不强杀应用。不同macOS用户独立使用。

本机已验证8路互斥竞争、锁释放/过期进程号/崩溃恢复，以及6个真实App重复启动仅保留1个进程和1个主窗口。单实例组件以编译警告作为错误检查通过。没有重启代理或更改节点偏好。

## 自启动与停止

开关只改变代理后台LaunchAgent是否启用；关闭开关不结束当前进程。主动停止会写入既有暂停状态，后续需显式启动。登录自启动是用户登录后的服务，不是登录前系统daemon。原生界面本身没有被添加到登录项。

启动可能等待现有管理器的就绪检查。状态桥接等待20秒后返回超时提示，避免无限等待；启动/停止保留更长独立预算。超时/失败不保证动作完全未发生，界面明确要求刷新确认，不自动重试。停止操作须经界面确认；既有连接会断开，网络恢复逻辑由现有管理器执行。

## 安全与兼容范围

- 控制层使用固定参数数组与操作白名单，不通过shell执行用户输入。
- 仅读取配置/状态的有限字段，不读取 `proxy.secret`、SSH私钥、root密码或OAuth参数。
- 豆包保护仍是PAC域名DIRECT，不是操作系统按进程排除。实时PAC不可读时不显示已验证保护。
- 不拦截或解密HTTPS；不改服务端BBR、生产默认节点与候选集合。
- 可信项目管理脚本会被执行，本版不是运行任意项目代码的隔离环境。
- 现有部署仍限定Wi-Fi；本版不自动接管其他网络服务。
- App使用本地ad-hoc签名，未配置Developer ID、未公证，不宣称可直接公开分发或已通过另一台Mac验收。不要关闭Gatekeeper；签名/公证应在发布流程完成。

## 构建与测试

从仓库根目录执行：

```bash
python3 apps/macos/Tests/test_bridge.py
xcrun swiftc -parse-as-library -swift-version 5 \
  apps/macos/Sources/ProxyStore.swift apps/macos/Sources/NativeStatus.swift \
  apps/macos/Tests/model-tests.swift \
  -o dist/macos-client/model-tests
./dist/macos-client/model-tests apps/macos/Tests/demo.json
python3 apps/macos/build.py --output dist/macos-client-build
```

`build.py`拒绝覆盖已有App，使用新的输出目录。构建需要已安装并授权的Xcode/Swift SDK。产物manifest保存App文件hash。

演示界面使用文档保留地址而非生产数据；`Socks5Proxy.app/Contents/MacOS/Socks5Proxy --demo`只读fixture，禁止所有代理操作。演示状态不是实际网络结果。
