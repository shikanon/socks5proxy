# 每日令牌表 TUN 隧道验证记录

2026-10-24 完成 `tcp-table` 实现及国内服务器至海外服务器的真实网络测试。最终结果通过。

## 实现

- 普通 TCP，无 TLS 证书；服务端首次启动生成 256 项随机令牌表，每项 8–16 位，默认 16 位。
- 自动保存私有 JSON 文件，后续启动复用；两端共享同一张表。
- 整张表和 UTC 当日零点 Unix 时间戳派生每日字节双射，数据帧携带日期，兼容跨午夜。
- 共用已有 TCP 随机挑战及双向 HMAC 认证、TUN 全局 IPv4 路由、DNS/NAT、断线重连和停止恢复。
- 桌面 CLI 支持 `-transport tcp-table`；移动端 Go 核心支持配置 JSON 中的 `token_table`，原生界面暂未增加导入入口。

使用说明见[令牌表隧道](token-table.md)。这是学习用字节替换算法，没有数据完整性或重放防护，也不具备现代密码算法的保密性。
